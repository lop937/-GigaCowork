# Агент распределения ФУЛ между логистами

Тестовое задание GigaCowork. Ссылка на проект.

## Что лежит в репозитории

В соответствии с требованиями к сдаче, здесь находятся только итоговые артефакты:

1. **Агент_распределения_ФУЛ.zip** — архив агента: навык `logist-distribution.zip`, системный промпт и инструкция по установке.
2. **Тестовые_данные_GigaCowork.zip** — тестовые данные: выгрузка ФУЛ, реестр Cloud, сотрудники, эталон и генератор.
3. **Отчёт_распределение_ФУЛ.pdf** — PDF-отчёт: вопросы заказчику, алгоритм, принятые допущения, описание данных, результаты прогонов, скриншоты и мотивация.
