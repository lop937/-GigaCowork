# Агент распределения ФУЛ между логистами

AI-агент на GigaCowork для распределения новых упаковочных листов (ФУЛ)
между логистами. Определяет новые ФУЛ и повторные отправки, выбирает группу
и логиста по правилам заказчика, готовит строки реестра Cloud строго по его
форме и список «Требует внимания».

Все компании, бренды и сотрудники вымышленные. Данные синтетические.

## Состав репозитория

| Файл | Что это |
|---|---|
| `Агент_распределения_ФУЛ.zip` | Архив агента: навык (`logist-distribution.zip`), системный промпт, инструкция по установке |
| `Тестовые_данные_GigaCowork.zip` | Тестовые данные: выгрузка ФУЛ, реестр Cloud, сотрудники, эталон, генератор |
| `run_agent.py` | Python-обёртка harness: запускает скрипт навыка и пересказывает результат через GigaChat API |
| `run_metrics.py` | Контрольные прогоны и метрики по эталону |
| `Таблица_решений.md` | Алгоритм распределения в виде таблицы решений |
| `out_A/metrics_A.json`, `out_B/metrics_B.json` | Метрики прогонов (набор A и B — с перемешанными колонками/листами) |
| `out_A/run1/stdout.txt` | Лог одного прогона скрипта навыка |
| `out_agent/agent_log.txt` | Лог прогона harness (прогон 1); `agent_log_run2.txt`, `agent_log_run3.txt` — прогоны 2 и 3 |

## Как работает агент

1. Пользователь прикладывает три файла Excel: выгрузку ФУЛ из 1С, реестр Cloud и список сотрудников из 1С. Порядок и имена файлов не важны, тип определяется по заголовкам колонок.
2. Скрипт навыка `distribute.py` применяет правила заказчика: определяет новые ФУЛ и повторные отправки, группу и логиста, готовит строки Cloud по форме реестра.
3. Языковая модель (GigaChat) получает вывод скрипта и пересказывает его пользователю по шаблону. Сама ничего не решает и не придумывает.
4. Результат — Excel-файл `Результат_распределения_ФУЛ.xlsx`: новые строки Cloud, повторные отправки, возможные пропуски, «Требует внимания», журнал решений с обоснованием по каждому ФУЛ.

Агент ничего не записывает в Cloud и 1С, не использует сеть и внешние интеграции.

## Установка навыка в GigaCowork

1. Распакуйте `Агент_распределения_ФУЛ.zip`.
2. Загрузите `logist-distribution.zip` как навык (в архиве папка `logist-distribution/` с файлом `SKILL.md`).
3. Создайте агента, вставьте текст `system_prompt.txt` как системный промпт и подключите навык.
4. Выберите агента, приложите три файла Excel и отправьте сообщение без текста.

Подробнее — в `INSTALL.md` внутри архива.
